SJ MEDIA Website
A responsive, custom-coded one-page website for SJ MEDIA using HTML, CSS, and vanilla JavaScript.
Files
index.html — page content and sections
styles.css — responsive premium dark/gold styling
script.js — mobile navigation, year, and WhatsApp enquiry form
Before publishing
Open index.html and check all copy.
In script.js, replace 233XXXXXXXXX with your WhatsApp number in international format. For Ghana, use 233 plus the number without the first 0 and without +.
In index.html, replace hello@sjmedia.example and “Add your business email” with your real business email, or remove that contact line if you don't want to publish an email yet.
Check the services to make sure they are services you are ready to offer.
The portfolio cards are clearly labelled concept previews; they are not real client projects. Keep that disclaimer until you replace them with genuine work.
Preview locally
Open index.html in a browser. For a more reliable local preview, use any simple static-file server or a code editor's preview feature.
Publish free with GitHub Pages
Create/sign in to a GitHub account.
Create a new public repository named sj-media-website.
Upload index.html, styles.css, and script.js to the repository root (not inside an extra nested folder).
In the repository, open Settings → Pages.
Under build/deployment, select Deploy from a branch, choose main and /(root), then save.
Wait for the deployment to finish. GitHub Pages will show the public website URL in the Pages section.
Open the URL on your phone and test every navigation link and the contact form.
A free hosting address will be a GitHub Pages URL. A custom domain is optional and may cost money. Do not upload passwords, private client information, or secret credentials to a public repository.
Notes
This is a static website; it does not need a paid server or database.
The enquiry form opens WhatsApp and prepares a message; it does not store submissions on the website.
Google Fonts are loaded from Google Fonts when an internet connection is available; fallback fonts are included.
